# Happinometer — เว็บแอพประเมินความพึงพอใจผู้ป่วย

เว็บแอพพลิเคชันสำหรับพยาบาลประจำจุด **รับใบนัด/ให้คำแนะนำ** และจุด **Discharge** เปิดบนมือถือของตนเองแล้วยื่นให้ผู้ป่วยกดประเมินความพึงพอใจหลังรับบริการ พร้อม **Dashboard แบบ Real-time** ภายในแอพ และบันทึกข้อมูลลง **Google Sheets** อัตโนมัติ

- **Google Sheet ที่เชื่อมต่อแล้ว:** [Happinometer Sheet](https://docs.google.com/spreadsheets/d/1L-0DYUb9wQJ4eHLKeJ4pGCOn3A5ENnuIaaXbH70j74I/edit?gid=0#gid=0)

---

## จุดเด่นของ Happinometer

- **จำห้องตรวจที่ใช้ล่าสุดเป็นค่าเริ่มต้น (Default)** — ตั้งค่าหน่วย ห้องตรวจ และจุดบริการเพียงครั้งเดียว ครั้งต่อไปเปิดมากด **"เริ่มประเมิน"** แล้วยื่นให้ผู้ป่วยได้ทันที (รองรับการสลับห้องเร็วจากแถบ "ใช้ล่าสุด")
- **ครบทุกหน่วยและห้องตรวจเดิม** — ดึงโครงสร้าง **14 หน่วย / 36 ห้องตรวจ** จากงาน OPD & Nurse Note Audit พร้อมรองรับห้องตรวจเพิ่มเติม ("อื่นๆ")
- **เก็บข้อมูลครบถ้วน** — จำนวนผู้ประเมิน (`N`), เพศ, ช่วงอายุ (5 ช่วงวัย), สิทธิ์การรักษา (`บัตรทอง` / `เบิกตรง` / `ประกันสังคม` / `ชำระเงินเอง`), และคะแนนความพึงพอใจ **1–5** ด้วยตัวการ์ตูนหน้าแสดงอารมณ์แบบมีมิติและแอนิเมชันน่ารัก
- **ออกแบบสำหรับยื่นให้ผู้ป่วยกดง่าย** — ปุ่มใหญ่ อ่านชัด ใช้เวลาไม่ถึง 10 วินาที มีเสียง/สั่นตอบสนอง เอฟเฟกต์ Confetti หน้าขอบคุณ และนับถอยหลังกลับหน้าแรกอัตโนมัติ (หากผู้ป่วยวางทิ้งไว้ 90 วินาทีจะกลับหน้าแรกเอง)
- **Real-time Dashboard ในตัวแอพ** — แสดงมาตรวัด Happinometer, คะแนนเฉลี่ย, ร้อยละความพึงพอใจ, การกระจายคะแนน 1–5, กราฟแยกเพศ/ช่วงอายุ/สิทธิ์การรักษา, กราฟแนวโน้ม (รายชั่วโมง/รายวัน/รายเดือน), ฟีดผลประเมินล่าสุดแบบ Live และตารางเปรียบเทียบรายหน่วย/รายห้อง พร้อมส่งออก **CSV**
- **Offline-first Queue** — หากสัญญาณอินเทอร์เน็ตในโรงพยาบาลสะดุด แอพจะเก็บข้อมูลลงคิวในเครื่องไว้ก่อนและส่งขึ้น Google Sheet อัตโนมัติทันทีที่กลับมาออนไลน์ (ป้องกันข้อมูลซ้ำด้วยระบบ ID)

## วิธีเชื่อมต่อ Google Sheet และเปิดใช้งานจริง (แนะนำ — ง่ายที่สุด)

วิธีนี้จะให้ Google Apps Script โฮสต์ตัวแอพโดยตรง **ไม่ต้องเช่าเซิร์ฟเวอร์** และ **ไม่ต้องตั้งค่า URL เพิ่ม** ในแอพ:

1. เปิด [Google Sheets](https://sheets.google.com) แล้วสร้างสเปรดชีตใหม่ ตั้งชื่อว่า **`Happinometer`**
2. ไปที่เมนู **ส่วนขยาย (Extensions)** → **Apps Script**
3. ในไฟล์ `Code.gs` ให้ลบโค้ดเดิมทั้งหมด แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ `Code.gs` ในโฟลเดอร์นี้ไปวาง → กด **บันทึก (Ctrl+S)**
4. กดปุ่ม **`+`** ข้างคำว่า **ไฟล์ (Files)** → เลือก **HTML** → ตั้งชื่อว่า **`index`** (ไม่ต้องใส่ `.html`)
5. ลบโค้ดเดิมในไฟล์ `index.html` แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ `index.html` ในโฟลเดอร์นี้ไปวาง → กด **บันทึก (Ctrl+S)**
6. (ไม่บังคับ) เลือกฟังก์ชัน `setupSheets` ด้านบนแล้วกด **เรียกใช้ (Run)** เพื่ออนุญาตสิทธิ์เข้าถึงและสร้างหัวตารางล่วงหน้า
7. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** → **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - กดรูปเฟือง เลือกประเภทเป็น **เว็บแอป (Web app)**
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)`
   - กด **ทำให้ใช้งานได้ (Deploy)** แล้วกดอนุญาตสิทธิ์ (Authorize access)
8. คัดลอก **URL ของเว็บแอป** ส่งเข้าไลน์กลุ่มพยาบาล หรือทำ QR Code ให้พยาบาลเปิดบนมือถือแล้วกด **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"** ใช้งานเหมือนแอพจริงได้เลย

> **กรณีโฮสต์ `index.html` แยก** (เช่น บน GitHub Pages / Netlify หรือเปิดในเครื่อง):
> ทำตามขั้นตอนที่ 1–3 และ 7–8 (ข้ามข้อ 4–5 ได้) จากนั้นเปิดแอพ Happinometer → ไปที่แท็บ **ตั้งค่า** → วาง **Web App URL** → กด **บันทึก URL** แล้วกด **ทดสอบการเชื่อมต่อ**

## โครงสร้างชีตใน Google Sheet ที่สร้างให้อัตโนมัติ

- **`Summary`** — ตารางสรุปรวมทุกหน่วย/ห้องตรวจ (จำนวน N, คะแนนเฉลี่ย, ร้อยละ, พอใจระดับ 4–5, และจำนวนคะแนน 1–5) อัปเดตอัตโนมัติทุกครั้งที่มีผลประเมินใหม่
- **`Responses`** — ข้อมูลดิบทุกรายการ (ID, Timestamp, วันที่, เวลา, หน่วย, ห้องตรวจ, จุดบริการ, เพศ, ช่วงอายุ, สิทธิ์การรักษา, คะแนน, ระดับความพึงพอใจ, อุปกรณ์)
- **ชีตแยกตามหน่วย** (เช่น `หน่วยที่ 1`, `หน่วยผ่าตัดเล็ก`, `เคมีบำบัด`) — สร้างและแยกข้อมูลให้อัตโนมัติ (ปิดได้โดยแก้ `SPLIT_BY_UNIT: false` ใน `Code.gs`)

## ทดลองใช้งานในเครื่องทันที

สามารถดับเบิลคลิกเปิดไฟล์ `index.html` หรือรันผ่าน Local Server เพื่อทดลองใช้งานได้ทันที (ในโหมดออฟไลน์จะมีข้อมูลตัวอย่างให้ดู Dashboard ก่อนเชื่อม Google Sheet และสามารถล้างข้อมูลตัวอย่างได้ในหน้า **ตั้งค่า**):

```powershell
cd C:\Users\User\.gemini\antigravity\scratch\happinometer
python -m http.server 8765
```

แล้วเปิด `http://localhost:8765` ในเบราว์เซอร์
